How to use it

Importing or creating a font:
You can either:
  • Extract a font by copying & pasting the existing font source (a .h file) in the textarea above
  • Create a new font with a single character
Adding characters:

You can easily add new characters to the font afterwards, including Unicode characters above 0xFF. The gap to the nearest character can be filled with disabled glyphs; otherwise the character starts a new segment.

Segmented UTF-8 fonts:

Fonts declared as UTF8_32BitFont[] (an array of segments, each a GFXfont plus 32-bit dFirst/dLast, ended by a null entry) can be imported too. Only one font per file is edited.

Editing glyphs:
Glyphs can be edited individually. You can:
  • Enable or disable the glyph
  • Edit each pixel of the glyph
  • Edit all values present in the GFXglyph data structure (See Adafruit documentation for more information)
When exporting:

The format is chosen automatically: a plain GFXfont when the characters form one range within 0x00–0xFF, otherwise a segmented UTF8_32BitFont[] (one segment per range of consecutive characters). Pack bitmaps lets glyphs share overlapping bytes of the bitmap array (identical glyphs stored once), which makes the font smaller; offsets in the glyph table are then no longer in order. You can either:

  • Select a range of characters to include in the output. Characters outside of this range will not be included in the bitmap nor in the glyphs table.
  • Disable individual characters. The disabled characters get all values set to 0. There still are entries for the disabled characters in the glyphs table, but no data in the bitmap for them — this keeps the characters in their correct places in the ASCII table.
